# Online Fix 游戏下载

一个 AstrBot 插件：用户说一句「我想玩 xxx」（或 `/game xxx`），插件同时搜索
[online-fix.me](https://online-fix.me/)（带联机补丁的全量游戏）与
[gamer520.com](https://www.gamer520.com/)（游戏本体），并返回下载链接。

## 功能

- 自然语言入口：`我想玩赛博朋克2077`、`我要玩黑神话悟空`、`帮我找死亡搁浅`
- 命令入口：`/game 赛博朋克2077`
- online-fix.me 全量游戏条目：返回详情页、服务器直链（优先解析 `Fix Repair` 目录里的 `.rar`）、备用网盘/Drive 链接与解压密码
- gamer520.com 游戏本体：返回文章页与网盘链接（含提取码），未找到联机补丁时明确标注
- 中文游戏名经 Steam 商店查询解析为官方英文名，供 online-fix.me 搜索；解析失败时退回原词，并提示改用 `/game <英文名>` 重新搜索
- ⚠️ **online-fix.me 目前仅支持英文游戏名检索**：中文名需先经 Steam 解析为英文名才能在该站命中；非 Steam 游戏或解析失败时，该站检索不到结果（gamer520.com 始终用中文检索，不受影响）
- 模糊匹配：允许部分命中（如「赛博朋克」匹配「赛博朋克2077」）
- 搜索结果与名称解析结果缓存 24 小时（可配置），支持配置手动清空
- 随机 UA、请求间隔与反爬挑战重试，降低被识别为爬虫的风险

## 安装

将本目录放入 AstrBot 的 `data/plugins/` 下，然后在 WebUI 插件管理页启用。
插件依赖 `httpx` 与 `beautifulsoup4`，AstrBot 会依据 `requirements.txt` 自动安装。

## 使用

```
我想玩赛博朋克2077
/game 黑神话悟空
```

回复为纯文本：全量游戏条目优先，其次才是游戏本体；若某站点暂时不可用会注明。

## 配置

在 AstrBot 插件管理页可修改以下配置：

| 配置项 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `result_count` | int | 3 | 每次回复返回的候选数量 |
| `cache_ttl` | int | 24 | 搜索结果缓存有效期（小时） |
| `clear_cache` | bool | false | 设为 true 后，在下次查询时清空全部缓存并自动复位为 false（游戏更新后强制刷新用） |
| `request_timeout` | int | 60 | 单个来源的请求总超时（秒） |

## 说明与免责声明

- online-fix.me 的压缩包解压密码固定为 `online-fix.me`；gamer520.com 文章页若标注了解压密码会一并返回。
- online-fix.me 仅支持英文游戏名检索；非 Steam 游戏或 Steam 解析失败时请改用 `/game <游戏英文名>` 搜索。
- 两站页面结构与链接可能随时变化，若解析失效请反馈更新选择器。
- 插件只返回第三方站点公开页面上的下载链接，不代下载、不提供文件本身；下载内容请自行甄别风险。
- 数据请求受 24 小时缓存与频率控制约束，但仍请合理使用，遵守目标站点条款。
