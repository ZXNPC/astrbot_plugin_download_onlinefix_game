# Online Fix 游戏下载

一个 AstrBot 插件：用户说一句「我想玩 xxx」（或 `/game xxx`），插件同时搜索
[online-fix.me](https://online-fix.me/)（带联机补丁的全量游戏）与
[gamer520.com](https://www.gamer520.com/)（游戏本体），并返回下载信息。

## 友情推荐

若需要更方便地下载 online-fix.me 的联机补丁，推荐 [online-fix-helper](https://github.com/Leeanran2026/online-fix-helper)。本插件目前只返回资源信息、页面指引与可独立访问的网盘链接，不做站内补丁的一键下载；该工具可以补足这一使用场景。

## 功能

- 自然语言入口：`我想玩赛博朋克2077`、`我要玩黑神话悟空`、`帮我找死亡搁浅`
- 命令入口：`/game 赛博朋克2077`
- online-fix.me 全量游戏条目：返回详情页、可独立访问的网盘链接（如有）与解压密码，并附下载指引
- gamer520.com 游戏本体：自动解析文章正文与二维码网盘链接，并跟随“立即获取/获取资源”链路返回真实网盘地址（含提取码）；过滤修改器、金手指等非游戏本体分类
- 插件不做中英文名自动转换：online-fix.me 与 gamer520.com 均按你的输入原样检索；未命中时回复会提示可尝试中英文各搜一遍（如 `/game 艾尔登法环` 与 `/game Elden Ring`）
- ⚠️ **online-fix.me 只收录带联机补丁/联机方案的游戏，且以英文名收录**：中文输入在该站通常无命中；找不到游戏或补丁时，请中英文各搜一遍（gamer520.com 以中文收录游戏本体）
- 模糊匹配：允许部分命中（如「赛博朋克」匹配「赛博朋克2077」）
- 搜索结果缓存 24 小时（可配置），支持配置手动清空
- 随机 UA、请求间隔与反爬挑战重试，降低被识别为爬虫的风险

## 安装

将本目录放入 AstrBot 的 `data/plugins/` 下，然后在 WebUI 插件管理页启用。
插件依赖 `httpx` 与 `beautifulsoup4`，AstrBot 会依据 `requirements.txt` 自动安装。

## 使用

```
我想玩赛博朋克2077
/game 黑神话悟空
```

回复为纯文本：全量游戏条目优先，其次才是游戏本体；若某站点暂时不可用会注明。

## 配置

在 AstrBot 插件管理页可修改以下配置：

| 配置项 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `result_count` | int | 3 | 每次回复返回的候选数量 |
| `cache_ttl` | int | 24 | 搜索结果缓存有效期（小时） |
| `clear_cache` | bool | false | 设为 true 后，在下次查询时清空全部缓存并自动复位为 false（游戏更新后强制刷新用） |
| `request_timeout` | int | 60 | 单个来源的请求总超时（秒） |
