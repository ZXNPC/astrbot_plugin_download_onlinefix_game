# 0003 - 放弃自动名称解析，改为双语重试提示

## Status

Accepted

## Context

ADR-0002 的 Steam 商店两步解析只覆盖「Steam 上存在中文官方名」的游戏，非 Steam 游戏、
俗称、区域不可见等都会解析失败。曾评估改为「LLM + 网页搜索自动获取游戏中英文名」，
2026-09-02 的调研（含实测抽样）显示该路线复杂度与收益不成比例：

- AstrBot（本机 v4.20.0）内置网页搜索是注册给普通对话 agent 的 llm_tool，插件无法直接
  import 调用；新版 AstrBot 已把内置搜索改版，能力随版本漂移。
- 不存在零 key 的免费 LLM；免费档（SiliconFlow、智谱等）都需注册 key。
- gamer520.com（品牌 Switch520）游戏标题实测约 68% 为纯中文、仅约 30% 中英并存，
  且纯中文标题的文章页元数据也多数不含英文名 → 中文站无法反向提供英文佐证。
- online-fix.me 只收录站方发布了联机补丁/联机方案的游戏（含社区 mod 联机，如只狼），
  纯单机游戏普遍搜不到；「搜不到」无法区分「游戏未被收录」与「英文名不对」。

自动方案需要模型 key、双语方向选择与一整套防误判校验链，显著增加配置面与维护成本。
权衡后决定：**不做任何自动中英文名转换**，让工具保持简单。

## Decision

- 移除名称解析功能（含 `app/name_lookup.py` 的 Steam 两步解析及其调用链、`names` 缓存段
  与旧 `translate` 段懒迁移）。
- 两个搜索源一律使用用户请求**原词**检索：online-fix.me 不再自动喂入英文名，
  gamer520.com 也不再做任何改写。
- 新增**双语重试提示**：整体未找到，或某来源可用但未命中（另一来源有结果）时，
  回复提示用户可分别用中文、英文再搜；来源不可用（网络/站点故障）时不显示该类提示，
  维持原有「暂时无法访问」文案。
- 版本升至 v0.10.0；ADR-0002 标记为 Superseded。

## Consequences

- online-fix.me 的命中依赖用户主动提供英文名：中文原词在该站通常无命中属预期，
  提示引导用户自行双语重搜，插件不再猜测或翻译。
- 插件零 LLM/翻译/Steam 依赖：无 key、无 token 成本、无额外请求来源，缓存与配置面更小。
- 若将来仍需要自动转换，可基于本 ADR 记录的调研事实重新评估（例如用户自配免费 provider
  + 插件自备网页搜索），但默认形态保持简单。
